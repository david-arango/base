# Base GitHub Pages

This folder contains the static files for GitHub Pages for the Base Budgeting App project.

## Files

- `index.html` - starter homepage
- `.nojekyll` - disables Jekyll processing on GitHub Pages

## GitHub Pages setup

If you want to publish this folder as the GitHub Pages site:

1. Open the repository settings
2. Go to Pages
3. Source: Deploy from a branch
4. Branch: `dev`
5. Folder: `/docs`

This will publish the site from the `docs` directory on the `dev` branch.
